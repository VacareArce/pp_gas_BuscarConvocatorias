Agente Empleos HV

Manual de uso

Guia rapida para configurar y operar el buscador pasivo de empleos desde Google Sheets.

Inicio rapido

  1. Configura la propiedad del script GEMINI_API_KEY en Apps Script.
  2. Ejecuta Agente Empleos HV > Configurar estructura.
  3. Diligencia la pestaña Perfil con datos del CV.
  4. Revisa la pestaña Config, especialmente salarios y prompts.
  5. Ejecuta Instalar trigger diario.
  6. Revisa periodicamente Empleos, ColaIA y Log.

Reglas clave

  • El agente funciona de forma pasiva con trigger diario.
  • No aplica automaticamente a empleos.
  • Si una oferta no publica salario, debe quedar como Revisar, no Aplicar.
  • Los prompts se pueden editar desde Config.
  • Las variables con {{doble_llave}} las reemplaza Apps Script antes de llamar a Gemini.
Que hace el agente

El agente busca empleos remunerados alineados con un perfil profesional. Luego analiza cada oportunidad y la clasifica por modalidad, viabilidad desde la ciudad base, salario, compatibilidad y accion recomendada.

El flujo diario ejecuta una busqueda pequeña y analiza un lote limitado para cuidar la cuota gratuita de Gemini.

Como diligenciar Perfil

La hoja Perfil es el insumo principal de busqueda. Mientras mas claro sea el perfil, mejores resultados tendra la IA.

CampoQue poner
Profesion principalProfesion, especialidad y enfoque principal.
Anios de experienciaExperiencia total aproximada para evitar cargos demasiado junior.
Areas fuertesTemas donde la persona tiene experiencia real.
Cargos objetivoTitulos de cargos que se deben priorizar.
Texto completo CVTexto extraido del PDF o resumen amplio del CV.
Las celdas de la columna A tienen notas descriptivas. Pasa el mouse sobre cada campo para ver ayuda.
Como ajustar Config

La hoja Config controla el comportamiento sin modificar codigo.

EMPLEOS_POR_LOTE_ANALISISMaximo de empleos analizados por lote.

Salarios y multiplicadores

El sistema usa un salario base y multiplicadores para exigir mejores condiciones cuando una oferta requiere mudanza.

ClaveEjemploSignificado
SALARIO_BASE_MONEDACOPMoneda de referencia.
SALARIO_BASE_MINIMO6500000Minimo para remoto o ciudad base.
MULTIPLICADOR_OTRA_CIUDAD_COLOMBIA2Minimo si exige mudarse dentro del pais.
MULTIPLICADOR_OTRO_PAIS3Minimo si exige mudarse a otro pais.

Ejemplo: con base 6.500.000 COP, otra ciudad exige 13.000.000 COP y otro pais 19.500.000 COP.

Prompts y variables con doble llave

Las variables con {{...}} son marcadores. Gemini no las interpreta directamente; Apps Script las reemplaza antes de enviar el prompt.

Ejemplo:

La persona vive en {{ciudad_base}}, {{pais_base}}.

Se convierte en algo como:

La persona vive en Medellin, Colombia.

VariableSignificado
{{perfil}}Texto construido desde la hoja Perfil.
{{empleo}}Datos de una fila de empleo durante el analisis.
{{empleos_existentes}}Resumen de empleos ya registrados para evitar duplicados.
{{salario_minimo_otra_ciudad_colombia}}Salario base multiplicado para mudanza dentro del pais.
{{salario_minimo_otro_pais}}Salario base multiplicado para mudanza internacional.
No cambies el nombre dentro de las dobles llaves si no existe en el codigo. Si escribes {{ciudad}} en vez de {{ciudad_base}}, no se reemplazara.
Como interpretar Empleos
ColumnaSignificado
ModalidadRemoto, Hibrido, Presencial o No claro.
Ejecutable desde MedellinIndica si se puede trabajar desde la ciudad base.
Puntaje matchCompatibilidad de 0 a 100.
Accion recomendadaAplicar, Revisar o Descartar.
EstadoSeguimiento manual: Nuevo, Revisado, Aplicado, Descartado o Vencido.
Cumple salarioSi, No o No claro segun la regla salarial aplicable.
Aplicar, Revisar y Descartar
  • Aplicar: alto ajuste, condiciones claras, viable desde ciudad base o cumple salario de mudanza.
  • Revisar: oportunidad interesante, pero falta confirmar salario, modalidad o requisitos.
  • Descartar: bajo ajuste, no remunerado, demasiado junior o no cumple criterios clave.
La IA recomienda. La decision final y el cambio de Estado a Aplicado o Descartado son manuales.
Ejecucion diaria y errores comunes

Para activar el flujo automatico usa Instalar trigger diario. Para detenerlo usa Eliminar triggers del agente.

ProblemaQue revisar
No aparece el menuRecarga la hoja. Si persiste, ejecuta onOpen desde Apps Script.
Error de API keyConfirma que existe la propiedad del script GEMINI_API_KEY.
No encuentra empleosCompleta mejor Perfil y revisa si el prompt es demasiado restrictivo.
Muchos resultados irrelevantesAjusta EXCLUIR, FUENTES_PRIORITARIAS y PROMPT_BUSQUEDA.
Errores 429 o 503Son cuota/saturacion. El sistema agenda reintentos diferidos.
Seguridad y privacidad
  • No pegues API keys en Config. Usa propiedades del script.
  • No publiques hojas de vida, telefonos, correos ni capturas con datos personales.
  • No publiques .clasp.json porque contiene el ID real del Apps Script.
  • Si subes el proyecto a GitHub, usa .clasp.example.json como plantilla segura.
