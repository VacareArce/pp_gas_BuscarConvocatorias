Plantilla copiable

Generador de prompts con apoyo de IA

Usa esta guia para pedirle a otra IA que genere los tres prompts principales del agente a partir de una hoja de vida.

Como usarlo

  1. Copia la plantilla completa del cuadro principal.
  2. Pegala en una IA conversacional junto con el texto de la hoja de vida.
  3. Completa los campos entre corchetes como [CIUDAD_BASE].
  4. Pidele que devuelva exactamente los tres prompts finales.
  5. Copia cada resultado en Config: PROMPT_BUSQUEDA, PROMPT_ANALISIS y PROMPT_ACTUALIZACION.

Reglas importantes

  • No pegues API keys ni datos sensibles innecesarios.
  • No cambies variables como {{perfil}} o {{empleo}}.
  • Los prompts deben pedir JSON estricto, sin Markdown.
  • Si no hay salario publicado, la accion debe ser Revisar, no Aplicar.
Plantilla para copiar y pegar en una IA

Copia todo este bloque y pegalo en una IA junto con el texto de la hoja de vida.

Como evaluar la respuesta de la IA
  • Debe entregar exactamente tres bloques: PROMPT_BUSQUEDA, PROMPT_ANALISIS y PROMPT_ACTUALIZACION.
  • Debe conservar intactas las variables con doble llave, por ejemplo {{perfil}}.
  • Debe pedir JSON valido y sin Markdown en cada prompt.
  • PROMPT_ANALISIS debe incluir reglas salariales por ubicacion.
  • Debe prohibir recomendar Aplicar cuando no hay salario publicado.
Si la IA cambia nombres de variables, corrige manualmente antes de pegar el prompt en Config. Una variable mal escrita no sera reemplazada por Apps Script.
